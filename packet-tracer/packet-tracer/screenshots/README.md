Project Screenshots

This folder contains visual evidence of the Operation NetGuard network security simulation.

The screenshots will document:

- Complete network topology
- HR, IT and SERVER VLAN configuration
- Router subinterface configuration
- Router interface verification
- Extended ACL configuration
- ACL application on the IT subinterface
- Successful HR-to-server connectivity
- Blocked IT-to-server connectivity
- ACL deny counter verification

These screenshots demonstrate the network implementation and testing performed using Cisco Packet Tracer.
