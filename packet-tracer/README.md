Packet Tracer Files

This folder contains the Cisco Packet Tracer simulation file and supporting documentation for Operation NetGuard.

Project Simulation

The simulation demonstrates:

- Separate HR, IT and SERVER VLANs
- Router-on-a-Stick inter-VLAN routing
- IEEE 802.1Q VLAN tagging
- Extended ACL-based access restrictions
- Controlled communication between departments
